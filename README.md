# JavaScript ES6 Practical Assignment 

This repository contains my **JavaScript ES6 Practical Assignment ** programs.  
The practical covers important ES6 concepts such as Classes, Promises, Async/Await, Array Methods, Spread/Rest Operators, Modules, Map, Set, `this`, and Arrow Functions.

## 📚 Programs Included

### 1. ES6 Integrated Programming Problem
- Student class and constructor
- Array of student objects
- `filter()` to find students scoring more than 60
- `map()` to extract student names
- `reduce()` to calculate average marks
- Template literals

### 2. Promise and Async/Await
- Promise creation
- Simulated student data retrieval
- `resolve()` and `reject()`
- `async` and `await`
- `try...catch`
- Template literals

### 3. Array Processing Challenge
- Product array
- `filter()` for products above ₹5,000
- `map()` to extract product names
- `reduce()` to calculate total price
- Object destructuring
- Template literals

### 4. Spread, Rest and Default Parameters
- Rest operator
- `reduce()` for calculating total
- Default discount of 10%
- Spread operator
- Template literals

### 5. Module-Based Application
- ES6 modules
- `export` and `import`
- Calculate total marks
- Calculate percentage
- Separate `student.js` and `app.js` files

### 6. Map and Set Application
- `Set` for unique student roll numbers
- Adding and deleting students
- `Map` for roll number and student name
- Retrieving student information
- `for-of` loop
- Counting unique students

### 7. `this` Keyword and Arrow Function
- Regular function and `this`
- Arrow function and `this`
- Difference between regular and arrow functions
- Correct use of `this` inside an object

### 8. Comprehensive ES6 Data Processing
- `filter()`
- `map()`
- `reduce()`
- Destructuring
- Template literals
- `Set`
- `for-of` loop
- Student data processing
